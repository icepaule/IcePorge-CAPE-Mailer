IcePorge CAPE-Mailer

E-Mail-getriggerte Malware- und Phishing-Analyse: verdächtige Anhänge einfach per Mail einreichen, automatisiert durch CAPE-Sandbox, Multi-Source-OSINT und ein LLM bewerten lassen und als HTML-Report zurückbekommen.

Python 3 · IMAP/SMTP-Poller · CAPEv2-Integration
Überblick Architektur Tech-Stack Quickstart

Überblick

CAPE-Mailer ist ein eigenständiges Python-Skript, das per Timer regelmäßig eine IMAP-Mailbox abfragt. Mitarbeiter können verdächtige Dateien (ausführbare Dateien, Skripte, Office-Dokumente, Archive) einfach als Anhang an eine dafür vorgesehene Adresse senden. Je nach Anhangstyp entscheidet das Tool automatisch, ob eine Malware-Analyse in einer CAPE-Sandbox oder eine Phishing-Analyse von EML/MSG-Dateien durchgeführt wird, reichert die Ergebnisse mit mehreren OSINT-Quellen und einer LLM-Bewertung an und schickt dem Einsender automatisch einen aufbereiteten HTML-Report zurück.

Zwei Analyse-Modi

Ausführbare Dateien, Skripte, Office-Dokumente und Archive gehen in die CAPE-Sandbox (Verhaltensanalyse). E-Mail-Dateien (.eml/.msg) durchlaufen stattdessen eine Header- und Phishing-Analyse (SPF/DKIM/DMARC/ARC).

Passwortgeschützte Archive

ZIP/7z/RAR-Archive werden automatisch entpackt — ein im Mail-Text mitgeschicktes Passwort wird per Regex erkannt, alternativ probiert das Tool eine Liste gängiger Standard-Passwörter.

Multi-Source OSINT

IPs, Domains und URLs werden gegen mehrere Threat-Intelligence-Quellen abgeglichen (Reputation, Sichtungen, Multi-Engine-Scans), URL-Prüfungen laufen über einen Tor-Proxy zum Schutz der Analysten-IP.

KI-gestützte Bewertung

Ein lokal gehostetes LLM bewertet die gesammelten Befunde kontextbezogen und liefert eine textuelle Risikoeinschätzung, die zusammen mit einem Ampel-System (grün/gelb/rot) in den Report einfließt.

Architektur

Ein Timer stößt das Skript in festem Intervall an. Es holt neue Mails per IMAP ab, klassifiziert die Anhänge, verteilt sie an die passende Analyse-Pipeline, reichert die Ergebnisse mit OSINT-Daten und einer LLM-Bewertung an und erzeugt daraus einen HTML-Report, der per SMTP an den Einsender zurückgeht. Kritische Funde können optional als strukturiertes Threat-Intelligence-Event exportiert werden.

Quickstart

Repository klonen und Konfiguration anhand der mitgelieferten Vorlage anlegen:

git clone https://github.com/icepaule/IcePorge-CAPE-Mailer.git
cd IcePorge-CAPE-Mailer

# Konfigurationsvorlage kopieren und anpassen
cp config.yaml.example config/config.yaml

# eigene IMAP/SMTP-Zugangsdaten, CAPE-Pfad und
# OSINT-/LLM-Einstellungen in config/config.yaml eintragen

python3 bin/cape_mailer.py

Für den Dauerbetrieb wird das Skript üblicherweise über einen systemd-Timer in kurzem Intervall (z. B. minütlich) gestartet, sodass eingehende Analyse-Anfragen zeitnah verarbeitet werden.
